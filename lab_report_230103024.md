## 3. Phase 2: strong and weak scaling

The deterministic formulas are fixed for all configurations. Stage A loops over floor(N/20) elements, starts x=1+(i%1024)*0.0001, and performs 12 iterations x=sqrt(1+abs(sin(x))), accumulating x. Stage B handles every element, starts x=0.1+(i%1024)*0.0001, and performs 35 iterations x=x*0.999+0.001+0.01*sin(x), accumulating x. All sqrt arguments are valid and checksums finite. Each worker returns a range and a scalar checksum; Stage A is serial in the parent. The formulas do not couple Stage A outputs into Stage B; both are deterministic parts of one timed pipeline. Strong checksums are compared across p with rel_tol=1e-10, abs_tol=1e-7; repeated checksums per configuration must be identical.

Variant 2 / Variant 1 measured rate ratio is 0.931283; best tiled / Variant 2 ratio is 0.945285. The best blocked configuration does not improve on Variant 2 in this run. In pure Python, extra loops, index arithmetic, memoryview element boxing, repeated C writes and interpreter dispatch can outweigh locality gains. No mandatory blocking speedup is assumed.

Each item starts x=0.25+(i%97)*0.001 and repeats x=sqrt(1+abs(sin(x)*cos(x))) exactly K(i) times. Kernels are identical for all strategies. Each item has a shared visit counter; every counter must equal one. Item counts, index sums and squared-index sums are also checked; checksums are compared with the independently calculated reference using rel_tol=1e-12 and abs_tol=1e-9. Results and raw per-worker active seconds and lambda are retained for every trial.

Static block assigns [t*N//p,(t+1)*N//p), which places the most expensive high-index items together. Static cyclic assigns t,t+p,... and spreads the increasing costs. Dynamic scheduling uses a single shared mp.Value counter; read and increment occur in the same locked critical section and work runs outside the lock. This is shared-counter dynamic scheduling, not work-stealing with per-worker queues. Worker active time includes chunk acquisition for dynamic runs and excludes waiting for the initial signal. lambda=max(worker time)/mean(worker time) is computed for each trial; the table reports the median of the nine trial lambdas, not a ratio of medians.

Static block / cyclic wall-time ratio: 2.167488; median imbalance lambda: 2.675376 versus 1.049486. Dynamic C=1 takes 2015.026625 ms with lambda 1.000957; C=1024 takes 3549.639833 ms with lambda 2.025218. Small chunks require more lock acquisitions; large chunks leave a coarser expensive tail and offer fewer opportunities to compensate for worker speed differences. The observed best chunk balances these costs for this run. P/E heterogeneity may affect worker rates, but no process-to-core assignment was established; lambda describes completion balance, not direct CPU utilization or proof of placement.

def _persistent_worker(conn, module_name, setup, worker_id, ready, go):
    """One command per trial; setup and reset occur before the common start."""
    import importlib
    module=importlib.import_module(module_name)
    state=None
    try:
        state=module.worker_setup(setup,worker_id)
        conn.send(('ready',None))
        while True:
            command=conn.recv()
            if command is None:
                break
            module.worker_reset(state,command,worker_id)
            ready.wait(timeout=600)
            go.wait(timeout=600)
            start=time.perf_counter_ns()
            result=module.worker_run(state,command,worker_id)
            duration=(time.perf_counter_ns()-start)/1e6
            conn.send(('ok',result,duration))
    except BaseException:
        try: conn.send(('error',traceback.format_exc()))
        except (BrokenPipeError, EOFError): pass
    finally:
        if state is not None:
            module.worker_close(state)
        conn.close()

class Team:
    def __init__(self,module,setup,p):
        self.p=p
        self.ready=CTX.Barrier(p+1)
        self.go=CTX.Barrier(p+1)
        self.conns=[]; self.procs=[]
        try:
            for t in range(p):
                parent,child=CTX.Pipe()
                proc=CTX.Process(target=_persistent_worker,args=(child,module,setup,t,self.ready,self.go))
                proc.start(); child.close()
                self.conns.append(parent); self.procs.append(proc)
            for conn in self.conns:
                self.receive(conn,'ready')
        except BaseException:
            self.close(abort=True)
            raise
    def receive(self,conn,status):
        deadline=time.monotonic()+7200
        while not conn.poll(0.1):
            if any(p.exitcode is not None for p in self.procs):
                raise RuntimeError('Worker exited before returning a result')
            if time.monotonic()>deadline:
                raise TimeoutError('Worker result timeout')
        value=conn.recv()
        if value[0]!=status:
            raise RuntimeError(str(value))
        return value
    def trial(self, command):
        for c in self.conns: c.send(command)
        self.ready.wait(timeout=600)
        start=time.perf_counter_ns()
        self.go.wait(timeout=600)
        values=[self.receive(c,'ok') for c in self.conns]
        elapsed=(time.perf_counter_ns()-start)/1e6
        return dict(elapsed_ms=elapsed, results=[v[1] for v in values],worker_ms=[v[2] for v in values])
    def close(self,abort=False):
        if not abort:
            for c in self.conns:
                try: c.send(None)
                except (BrokenPipeError,EOFError): pass
        for p in self.procs:
            if abort and p.is_alive(): p.terminate()
            p.join(timeout=10)
            if p.is_alive(): p.terminate(); p.join()
        codes=[p.exitcode for p in self.procs]
        for c in self.conns: c.close()
        if not abort and any(c != 0 for c in codes):
            raise RuntimeError(f'Worker exit codes: {codes}')
    def __enter__(self): return self
    def __exit__(self,typ,value,tb): self.close(abort=typ is not None)

def measure(trial, warmups=3, runs=9, check=None):
    for _ in range(warmups):
        r=trial()
        if check: check(r)
    records=[]
    for _ in range(runs):
        r=trial()
        if check: check(r)
        records.append(r)
    return dict(stats=asdict(summarize([r['elapsed_ms'] for r in records])), trials=records)

"""False sharing with one shared uint64 write on every iteration."""
import ctypes
import multiprocessing as mp
from multiprocessing import shared_memory
from harness import physical_count, Store, Team, measure, parser, partition, powers

MASK=0xFFFFFFFFFFFFFFFF
MULT=6364136223846793005

def fs_worker(shm_name, slot_idx, iters):
    shm=shared_memory.SharedMemory(name=shm_name)
    arr=(ctypes.c_uint64*512).from_buffer(shm.buf)
    try:
        acc=arr[slot_idx]
        for i in range(iters):
            acc=(acc*MULT+(i|1)) & MASK
            arr[slot_idx]=acc
        return acc
    finally:
        del arr
        shm.close()

def worker_setup(setup,t):
    shm=shared_memory.SharedMemory(name=setup['name'])
    return dict(shm=shm,arr=(ctypes.c_uint64*512).from_buffer(shm.buf),p=setup['p'],m=setup['m'])
def worker_reset(s,c,t): s['arr'][t*c['stride']]=0
def worker_run(s,c,t):
    arr=s['arr']; slot_idx=t*c['stride']; start,end=partition(s['m'],s['p'])[t]
    acc=arr[slot_idx]; mask=MASK; mult=MULT
    for i in range(end-start):
        acc=(acc*mult+(i|1)) & mask
        arr[slot_idx]=acc
    return acc

def worker_close(s):
    del s['arr']; s['shm'].close()

def expected(n):
    """O(log n) affine composition of paired updates, independently of workers."""
    # Pair i=2j,2j+1 both add 2j+1. Pair map: x'=m^2*x+(m+1)*(2j+1).
    def matmul(a,b):
        return [[sum(a[i][k]*b[k][j] for k in range(3)) & MASK for j in range(3)] for i in range(3)]
    m=MULT; a=[[m*m & MASK,2*(m+1)&MASK,(m+1)&MASK],[0,1,1],[0,0,1]]
    r=[[1,0,0],[0,1,0],[0,0,1]]; q=n//2
    while q:
        if q&1: r=matmul(r,a)
        a=matmul(a,a); q//=2
    acc=r[0][2]
    if n%2: acc=(acc*m+((n-1)|1)) & MASK
    return acc

"""Strong and weak scaling of a deterministic two-stage Python pipeline."""
import math
import multiprocessing as mp
import time
from harness import CTX, Store, measure, parser, partition

def stage_a(n):
    total=0.0
    for i in range(n//20):
        x=1.0+(i%1024)*0.0001
        for _ in range(12): x=math.sqrt(1.0+abs(math.sin(x)))
        total+=x
    return total

def stage_b(bounds):
    start,end=bounds; total=0.0
    for i in range(start,end):
        x=0.1+(i%1024)*0.0001
        for _ in range(35): x=x*0.999+0.001+0.01*math.sin(x)
        total+=x
    if not math.isfinite(total): raise RuntimeError('Nonfinite pipeline checksum')
    return start,end,total

def pool_ready(queue,gate):
    queue.put(mp.current_process().pid)
    gate.wait()

    for p in range(1,plog+1):
        todo=[('strong',strong),('weak',base*p)] if not all(f'{mode}_p{p}' in s.data['points'] for mode in ['strong','weak']) else []
        if not todo: continue
        queue=CTX.Queue(); gate=CTX.Event()
        pool=CTX.Pool(p,initializer=pool_ready,initargs=(queue,gate))
        processes=list(pool._pool)
        try:
            ready_pids=[queue.get(timeout=120) for _ in range(p)]
            if len(set(ready_pids))!=p: raise RuntimeError('Pool readiness mismatch')
            gate.set()
            for mode,n in todo:
                if f'{mode}_p{p}' in s.data['points']: continue
                bounds=partition(n,p)
                reference=[]
                def trial():

                    values=pool.map(stage_b,bounds,chunksize=1)
                    end=time.perf_counter_ns()

                def check(r):
                    if r['ranges']!=[list(x) for x in bounds]: raise RuntimeError('Pipeline ranges mismatch')
                    current=(r['checksum_a'],r['checksum_b'])
                    if reference and current!=reference[0]: raise RuntimeError('Pipeline repeated checksum mismatch')
                    if not reference: reference.append(current)
                    if mode=='strong' and 'strong_p1' in s.data['points']:
                        original=s.data['points']['strong_p1']['trials'][0]['checksum_b']
                        if not math.isclose(current[1],original,rel_tol=1e-10,abs_tol=1e-7): raise RuntimeError('Pipeline cross-process checksum mismatch')

def worker_run(s,c,t):
    A,B,C=s['views']; n=s['n']; start,end=s['bounds']; variant=c['variant']

        for i in range(start,end):

            for j in range(n):
                dot=0.0
                for k in range(n): dot+=A[row+k]*B[k*n+j]
                C[row+j]=dot
    elif variant==2:
        for i in range(start,end):
            row=i*n
            for k in range(n):
                a_ik=A[row+k]; brow=k*n
                for j in range(n): C[row+j]+=a_ik*B[brow+j]
    else:
        bs=c['bs']
        for ii in range(start,end,bs):
            imax=min(ii+bs,end)
            for jj in range(0,n,bs):
                jmax=min(jj+bs,n)

                    for i in range(ii,imax):
                        row=i*n
                        for k in range(kk,kmax):
                            a_ik=A[row+k]; brow=k*n
                            for j in range(jj,jmax): C[row+j]+=a_ik*B[brow+j]

"""Static and shared-counter dynamic scheduling of increasing-cost items."""
import math
import multiprocessing as mp
import statistics
import time
from harness import physical_count, CTX, Store, Team, measure, parser, partition

CHUNKS=[1,4,16,64,256,1024]

def item(i):
    x=0.25+(i%97)*0.001
    for _ in range(1+(i*i)//3600):
        x=math.sqrt(1.0+abs(math.sin(x)*math.cos(x)))
    return x

def worker_setup(setup,t): return setup

def worker_reset(s,c,t):
    s['times'][t]=0.0

def worker_run(s,c,t):
    start=time.perf_counter_ns(); n=s['n']; p=s['p']; values=[]; indices=[]
    def process(a,b,step=1):
        for i in range(a,b,step):
            values.append(item(i)); indices.append(i); s['visits'][i]+=1
    if c['strategy']=='block':
        a,b=partition(n,p)[t]; process(a,b)
    elif c['strategy']=='cyclic': process(t,n,p)
    else:
        chunk=c['chunk']
        while True:
            with s['counter'].get_lock():
                a=s['counter'].value
                s['counter'].value+=chunk
            if a>=n: break
            process(a,min(a+chunk,n))
    s['times'][t]=(time.perf_counter_ns()-start)/1e9
    return dict(checksum=math.fsum(values),items=len(indices),sum_indices=sum(indices),sum_squares=sum(i*i for i in indices))

def worker_close(s): pass

def main():
    args=parser(__doc__).parse_args(); n=120 if args.smoke else 12000; p=physical_count()
    s=Store('phase4',args,dict(N=n,pphys=p,chunks=CHUNKS,warmups=3,runs=9,checksum_rel_tol=1e-12))
    counter=CTX.Value('q',0); times=CTX.Array('d',p); visits=CTX.Array('i',n,lock=False)
    reference=math.fsum(item(i) for i in range(n))
    with Team('task4_scheduling',dict(n=n,p=p,counter=counter,times=times,visits=visits),p) as team:
        for strategy,chunk in [('block',None),('cyclic',None)]+[('dynamic',c) for c in CHUNKS]:
            def trial():
                counter.value=0
                for i in range(n): visits[i]=0
                r=team.trial(dict(strategy=strategy,chunk=chunk))
                wt=list(times[:]); r['worker_active_seconds']=wt
                r['lambda']=max(wt)/statistics.mean(wt)
                if any(v!=1 for v in visits): raise RuntimeError('Items were not visited exactly once')
                r['exactly_once_verified']=True
                return r
            def check(r):
                checksum=math.fsum(v['checksum'] for v in r['results'])
                if not math.isclose(checksum,reference,rel_tol=1e-12,abs_tol=1e-9): raise RuntimeError('Scheduling checksum mismatch')
                if sum(v['items'] for v in r['results'])!=n or sum(v['sum_indices'] for v in r['results'])!=n*(n-1)//2 or sum(v['sum_squares'] for v in r['results'])!=n*(n-1)*(2*n-1)//6:
                    raise RuntimeError('Scheduling item accounting mismatch')
            def bench():
                result=measure(trial,3,9,check)
                result.update(strategy=strategy,chunk=chunk,median_lambda=statistics.median(r['lambda'] for r in result['trials']),reference_checksum=reference)
                return result
            s.point(strategy+(f'_c{chunk}' if chunk else ''),bench)
    best=min((v for v in s.data['points'].values() if v['strategy']=='dynamic'),key=lambda v:v['stats']['median_ms'])
    s.data['C_star']=best['chunk']; s.finish(('PHASE4',s.data['points']['block']['stats']['median_ms'],best['stats']['median_ms']))

## Work sizes and timer boundaries

- Phase 0: 2,000,000 `perf_counter_ns()` reads per trial; mean loop cost includes Python overhead.
- Phase 1: exactly 24,000,000 shared uint64 writes per trial, 2 warmups and 7 timed repetitions. Strides 1/2/4/8/16/32 at Pphys; process sweep 1/2/4/8/10 at strides 1 and 16.
- Phase 2: strong N=1,600,000; weak N=p*250,000; every integer p=1..10. Permanent Pool per p, created before timers. Timed pipeline includes serial A and dispatch/results for B; separately records A duration.
- Phase 3a: two 96,000,000-byte buffers; 80,000,000 nominal arithmetic FLOPs per worker; Pphys workers. Initialization and worker startup are excluded.
- Phase 3b: N=384, all three variants and all ten block sizes. Shared matrices, disjoint output rows; C resets before timing. Correctness comparisons are outside timing.
- Phase 4: N=12,000; static block/cyclic and shared-counter dynamic chunks 1/4/16/64/256/1024. The latter is dynamic scheduling, not per-worker-queue work-stealing.

All phases except Phase 1 use 3 warmups and 9 timed repetitions. Worker teams synchronize readiness before the parent starts its timer. Timed wall intervals include common start-barrier release and receipt of small results. Worker active times exclude start waiting. Verification runs after the timed interval. Changed mutable state is reset before every trial. All timings use `perf_counter_ns()`; elapsed arrays are in milliseconds, Phase 4 active arrays explicitly in seconds. Rates convert milliseconds to seconds. OS scheduling and thermal/background conditions are uncontrolled, and no CPU affinity is claimed.

Three full GEMM double matrices occupy 3,538,944 bytes = 3.375 MiB, within the Performance-cluster L2 capacity but exceeding L1. The experiment keeps N=384 and Pphys=10, including Efficiency cores. Cache capacity does not guarantee residency. Python arithmetic throughput is not a hardware FLOP peak, and analytical traffic estimates are not measured DRAM traffic.
